Design Responsivo

O design responsivo é uma forma de criar páginas que conseguem se adaptar a diferentes tamanhos de tela.

Isso é importante porque uma página pode ser acessada por computadores, celulares e tablets.

Conceito

O design responsivo adapta a estrutura e a apresentação de uma página de acordo com o tamanho da tela.

Por exemplo, uma página pode ter três colunas em uma tela grande e apenas uma coluna em um celular.

O termo Responsive Web Design foi usado por Ethan Marcotte em 2010.

Principais técnicas

Grades e layouts fluidos

Utilizam tamanhos relativos para que os elementos possam ocupar diferentes espaços na página.

Imagens flexíveis

As imagens também precisam se adaptar ao tamanho da tela.

Um exemplo é: 

img {
    max-width: 100%;
}

Media Queries

As Media Queries permitem mudar o estilo da página dependendo do tamanho da tela.

Flexbox

O Flexbox é usado para organizar elementos em uma direção.

CSS Grid

O CSS Grid permite organizar elementos em linhas e colunas.

Viewport

O viewport ajuda a página a funcionar corretamente em diferentes dispositivos.

Mobile First

A ideia do Mobile First é começar o desenvolvimento pensando primeiro em telas pequenas e depois adaptar para telas maiores.

Frameworks

HTML e CSS já permitem criar páginas responsivas. Porém, alguns frameworks ajudam no desenvolvimento.

  • Bootstrap
  • Foundation

O Bootstrap possui um sistema de grid com 12 colunas, além de componentes prontos.

O Foundation também possui recursos para criação de layouts responsivos.

Os frameworks não são obrigatórios. A escolha depende do projeto, tempo, equipe e necessidade de personalização.

Exemplos

O design responsivo pode ser utilizado em vários tipos de sites.

  1. Sites de lojas virtuais
  2. Sites de notícias
  3. Sistemas acadêmicos
  4. Sites institucionais

Um exemplo conhecido é o site Boston Globe, que utiliza design responsivo.

Vantagens

  • Melhor experiência para o usuário
  • Funciona em diferentes dispositivos
  • Facilita a manutenção
  • Ajuda a página a funcionar em dispositivos diferentes

Desafios

  • Testar em vários tamanhos de tela
  • Cuidar do desempenho
  • Adaptar tabelas e menus
  • Adaptar formulários

Conclusão

O design responsivo é importante para a criação de páginas que funcionam em diferentes dispositivos.

Algumas das principais técnicas são layouts fluidos, imagens flexíveis, Media Queries, Flexbox, CSS Grid e Mobile First.

Mesmo utilizando frameworks como Bootstrap, é importante conhecer os fundamentos de HTML e CSS.

Também é importante pensar em usabilidade, acessibilidade, desempenho e testes.
